# Pre-existing Work Disclosure

NextRole is a new project created during the 2026 Agents for Humans Hackathon submission period.

The author previously developed independent projects that explored adjacent ideas:

- **CareerOS** — career and vacancy analysis concepts.
- **ProofTask** — structured human verification tasks and decision traces for AI-agent workflows.

At repository initialization, **no source code from those repositories has been copied into NextRole**. They are disclosed because their product and protocol ideas inform the direction of this project.

If pre-existing code is later reused or adapted, this file will be updated before submission with:

1. source repository and file/path;
2. whether code was copied, adapted, or only conceptually referenced;
3. the role of that component in NextRole;
4. the new hackathon work built around it.

Hackathon-specific work includes the NextRole product flow, Strands Agents orchestration, job-analysis tools, human decision gate integration, tests, user experience, architecture, and AWS deployment.
